# Built-in system / PC-control phrases (grammar: jarvis/intent_router.py).
# There is no skills/system directory; this table ships with the router.
# Loaded by the wiring layer with skill name "system".
#
# VIRTUAL TOOLS: these names are INTENT NAMES, not pc.* tools — the grammar
# cannot emit screen coordinates. The wiring layer (chat.py) must bind them:
#
#   system.observe_screen   -> pc.observe (tier-1, instant)
#   system.take_screenshot  -> pc.screenshot (tier-1)
#   system.launch_app{app}  -> pc.observe to find the app, then pc.click_element
#                              (tier-2 gate on the click, not on the words)
#   system.close_thing      -> pc.press_key(Alt+F4) or Escape (tier-2, gated)
#
# Destructive actions deliberately stay FUZZY-ONLY in practice: wiring must
# NEVER auto-execute system.close_thing / system.launch_app on any router
# Match without the normal tier-2 gate — the words are cheap, the click is
# what costs.
